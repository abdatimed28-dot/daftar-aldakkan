# دفتر الدكان — نسخة PWA تعمل دون إنترنت

## ما الذي أضيف؟
- ملف `manifest.webmanifest` لتعرّف المتصفح على التطبيق.
- ملف `sw.js` لتخزين واجهة التطبيق الأساسية مؤقتًا بعد أول زيارة ناجحة.
- أيقونتان بحجمي 192 و512 بكسل.
- تسجيل Service Worker داخل `index.html`.

## النشر على GitHub Pages
1. فك ضغط هذا الملف.
2. ارفع **كل الملفات الموجودة داخل المجلد** إلى جذر مستودع `daftar-aldakkan`، مع استبدال `index.html` والملفات القديمة عند الطلب.
3. انتظر نجاح GitHub Pages deployment.
4. افتح الموقع بالإنترنت مرة واحدة، وانتظر تحميله بالكامل.
5. جرّب وضع الطيران ثم افتح الموقع مجددًا.

## ملاحظات مهمة
- يلزم فتح الموقع مرة واحدة بالإنترنت حتى تُخزّن ملفات الواجهة.
- هذه الإضافة تخزّن واجهة التطبيق، ولا تضيف مزامنة بين الأجهزة.
- البيانات التي يحفظها التطبيق محليًا تبقى مرتبطة ببيانات المتصفح/التطبيق على ذلك الجهاز؛ خذ نسخة احتياطية بانتظام.
- اختبر وظائف التطبيق الأساسية في وضع الطيران قبل الاعتماد عليه في تسجيل ديون حقيقية.
